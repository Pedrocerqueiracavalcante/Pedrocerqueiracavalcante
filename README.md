Desenvolvedor focado em criar solucoes digitais completas, com frontend, backend, banco de dados, automacoes e deploy em cloud.

## Projeto em destaque

### Easy Clean Luxembourg

Plataforma para uma lavandaria ao domicilio em Luxembourg.

- Site moderno e responsivo.
- Area do cliente com pedidos, historico e tracking.
- Painel admin para gestao de pedidos.
- Banco Cloudflare D1 com Drizzle ORM.
- Deploy em Cloudflare Workers.
- Seletor de idioma para PT, EN, FR, DE e ES.
