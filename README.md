## Projeto em destaque

### Easy Clean Luxembourg

Plataforma para uma lavandaria ao domicilio em Luxembourg.

[![Abrir site](https://img.shields.io/badge/Abrir_site-Easy_Clean-2d6a2d?style=for-the-badge)](https://easyclean.cerqueirapedro275.workers.dev)
[![Ver codigo](https://img.shields.io/badge/Ver_codigo-GitHub-111111?style=for-the-badge&logo=github&logoColor=white)](https://github.com/Pedrocerqueiracavalcante/easyclean)

Principais pontos:

- Site comercial com visual moderno.
- Seletor de idioma: PT, EN, FR, DE e ES.
- Paginas de servicos com explicacao por tecido e produto.
- Area do cliente com pedidos, historico, tracking, perfil e subscricao.
- Painel admin com dashboard e gestao de pedidos.
- Deploy em Cloudflare Workers.
- Banco Cloudflare D1 com Drizzle ORM.
